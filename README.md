# 尾货街

> 线上地址：`https://weihuo.zangxixitech.cn`（Cloudflare Pages）
> 形态：零依赖纯静态站（HTML / CSS / JS，无构建步骤、无 npm 依赖）

## 当前阶段：先做「登录 + 绑定手机号」

前期**不做支付、不强制实名、不做会员开通**。先把最基础的登录绑手机跑通。

| 能力 | 现状 |
|---|---|
| 手机号绑定 | ✅ 可用（`/login`：号段校验 + 6 位码 + 60 秒倒计时 + 换绑/退出） |
| 收藏市场 / 登记意向 | ✅ 可用 |
| 加入微信群 | ✅ 可登记申请（客服拉群） |
| 实名认证 | ⏳ 未开放。页面已明示「筹备中」，**现阶段非必需** |
| 会员开通 | ⏳ 未开放。未登录→引导绑手机；已登录→登记意向（写 `wh_vip_apply_v1`） |
| 发布 / 联系商家 | ⏳ 表单就位，提交走客服人工通道 |

**登录实现**：纯静态站没有后端，登录态存在浏览器 `localStorage`（键 `wh_user_v1`）。
验证码默认走「本地验证模式」——真生成 6 位码并显示在页面上，可以走完整流程；
页面显著标注这是本地验证，**不伪装成已上线的短信通道**。
后续接后端时，只需注入 `window.WH_CONFIG = { smsApi, verifyApi }` 即自动切到真实短信通道，前端代码不用改。

## 数据来源与口径

站点内容来自公开渠道采集整理，**每条都标注溯源级别**：

| 徽标 | 含义 |
|---|---|
| 地图核验 | 可在腾讯地图等 POI 上直接核验到 |
| 多源核实 | 两个以上独立来源描述一致 |
| 公开行情 | 单一公开来源，仅用于价格区间参考 |

三条硬性口径：

1. **价格写成「公开行情区间」，不写单点报价** —— 尾货一货一价，行情不等于当天成交价；
2. **精确门牌号无核验时只到街道级**，不编门牌；
3. **单一来源的营销数字**（如「日均客流 X 万」）**一律不采**。

站内**不存在**编造的档口名、假手机号、虚构成交量。凡是平台给不出的信息（如档口电话），
页面直接说明「给不了、以及为什么」，而不是拿一个占位号糊上去。

## 部署方式

Cloudflare Pages，已连 Git 仓库（推 `main` 即自动部署）：

| 项 | 值 |
|---|---|
| Framework preset | None |
| Build command | （留空） |
| Build output directory | `/` |

`_headers`、`robots.txt`、`404.html`、`sitemap.xml` 放仓库根目录，CF Pages 自动识别。
`_live/`、`_bak/`、`shots/` 是本地工作目录，**不推送**。

## URL 约定（重要）

CF Pages 会把 `xxx.html` **308 重定向**到 `/xxx`。所以：

- **站内链接一律写干净 URL**（`/huoyuan`、`/detail`，首页写 `/`）；
- **canonical 一律指向干净 URL**；
- 本地预览请用 HTTP 服务器，**不要用 `file://` 打开** —— 资源用绝对路径 `/assets/...`，file 协议下会全部 404。

## 收录策略

- 可收录：`/`、`/shichang`、`/huoyuan`、`/caigou`、`/detail`、`/shop`、`/vip`、`/publish`、
  `/join`、`/about`、`/terms`、`/privacy`、`/disclaimer`、`/report-guide`
- `noindex`：`/me`、`/msg`、`/groups`、`/qiugou`、`/verify`、`/login`、`/404`
- 带参筛选页（`?q=` `?sort=` `?cat=`）在 robots 中禁止抓取，避免重复内容

## 验收

`_live/verify_auth.js` —— 真实浏览器（Chromium）跑 6 段断言：

| 段 | 内容 |
|---|---|
| A | 登录全流程（号段校验 / 验证码 / 倒计时 / 持久化 / 刷新 / 退出）19 项 |
| B | 会员页「立即开通」按钮不再是死按钮 10 项 |
| C | 待开放功能统一浮层 + 采购品类筛选 + 指南内容 14 项 |
| D | 市场收藏（未登录拦截 / 登录后收藏 / 取消）7 项 |
| E | 全站 21 页「点击无反应」巡检 |
| F | 专项：回到顶部（平滑滚动需轮询等稳定）+ 排序选中态转移 + 群筛选生效 |

E 段口径说明（避免误报与假绿）：

- **排除点击前已是当前选中项的按钮**（默认的「推荐」「综合」「全部品类」等）——
  点它保持不变才是正确行为，判「无反应」属误报；数量会打印出来；
- **排除回到顶部类按钮**（其唯一反馈是滚动位置），由 F 段「先滚下去再点」专测；
- 判定**不含 scroll 差异** —— Playwright 点击前会自动把元素滚进视口，
  拿自动滚动当按钮反应会产生假绿。
